## 🎯 Project Overview

This project demonstrates a complete supervised regression workflow:

1. **Data Generation** — A reproducible synthetic dataset of 500 students is created with realistic feature correlations.
2. **EDA** — Exploratory data analysis charts reveal relationships between features and scores.
3. **Preprocessing** — Duplicates removed, missing values imputed via median (no data leakage), features scaled.
4. **Training** — Four regression models are trained: Linear Regression, Ridge Regression, Random Forest, and Gradient Boosting.
5. **Evaluation** — Models are compared on a held-out test set using MAE, MSE, RMSE, and R².
6. **Dashboard** — An interactive Streamlit app lets users enter student attributes and instantly receive a predicted score, along with data insights and model comparison charts.

## 📂 Dataset

**Source:** Fully synthetic — generated by `data/generate_dataset.py` using NumPy.  
**No real student data is used.** The dataset is for educational / portfolio purposes only.

### Features

| Feature | Type | Range | Description |
|---|---|---|---|
| `study_hours_per_week` | Float | 2–40 | Average study hours per week |
| `attendance_percentage` | Float | 40–100 | Class attendance rate (%) |
| `previous_exam_score` | Float | 30–100 | Score on previous exam |
| `assignments_completed` | Int | 0–20 | Assignments submitted |
| `sleep_hours` | Float | 4–10 | Average nightly sleep (hours) |
| `parental_education` | Int | 0–4 | Parental education level |
| `tutoring_sessions` | Int | 0–10 | Extra tutoring sessions / month |
| `stress_level` | Float | 1–10 | Self-reported stress (1=low) |

**Target:** `final_score` — continuous, range 0–100.

The dataset deliberately includes 10 missing feature values and 5 duplicate rows for preprocessing practice.

## ▶️ Usage

### 1. Train models and generate outputs

```powershell
python main.py
```

This will:
- Auto-generate the dataset if it doesn't exist
- Run EDA and save charts to `outputs/`
- Train 4 regression models and save them to `models/`
- Evaluate models and save `outputs/metrics.json`
- Save test predictions to `outputs/test_predictions.csv`
- Run an example prediction and save `outputs/example_prediction.json`

### 2. Launch the Streamlit dashboard

```powershell
streamlit run app.py
```

Open your browser at **http://localhost:8501**

The dashboard has five sections:
- **🏠 Overview** — project summary, feature table, quick stats
- **📊 Data Insights** — dataset preview, statistics, EDA charts
- **🤖 Model Evaluation** — metrics table, comparison plots, residual analysis
- **🎯 Predict Score** — interactive form for real-time score prediction
- **ℹ️ About** — methodology, dataset details, limitations

## 🔬 Model Methodology

### Preprocessing Pipeline

All models use a shared `sklearn.Pipeline`:
1. **`SimpleImputer(strategy="median")`** — fills missing numeric values with the column median, fitted only on training data.
2. **`StandardScaler()`** — standardises each feature to zero mean and unit variance, again fitted only on training data.

This prevents any information from the test set leaking into the preprocessing step.

### Models

| Model | Key Hyperparameters | Notes |
|---|---|---|
| Linear Regression | default | Interpretable baseline |
| Ridge Regression | `alpha=1.0` | L2 regularisation reduces overfitting |
| Random Forest | `n_estimators=200, max_depth=8` | Captures non-linear interactions |
| Gradient Boosting | `n_estimators=200, lr=0.05, depth=4` | Sequential boosting, typically best |

### Train / Test Split

- **80% training, 20% testing** with `random_state=42` for reproducibility.
- Models are fitted **only on the training set**; the test set is used exclusively for evaluation.

## 📊 Evaluation Metrics

| Metric | Formula | Interpretation |
|---|---|---|
| **MAE** | mean\|y − ŷ\| | Average error in score points |
| **MSE** | mean(y − ŷ)² | Penalises large errors heavily |
| **RMSE** | √MSE | Same unit as target; easier to read |
| **R²** | 1 − SS_res/SS_tot | Proportion of variance explained (1.0 = perfect) |

The **best model is selected by R²** on the held-out test set.

## ⚠️ Limitations

- The dataset is **entirely synthetic** and small (~500 rows). Real-world performance may differ significantly.
- No **hyperparameter tuning** or **cross-validation** was performed.
- The synthetic target is constructed as a noisy linear function of the features, making linear models competitive. Real data relationships are more complex.
- **This project is for educational purposes only.** It must not be used to make real academic decisions about students.
